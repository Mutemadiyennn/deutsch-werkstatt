# Deutsch-Werkstatt

Persönliche Deutsch-Lern-App (A2 → B1+): Kontext-Karteikarten mit FSRS, Graded-Reader-Geschichten, Alltagsszenarien mit Sprechen, VHS-Synchronisation.

Läuft komplett im Browser (iPhone: in Safari öffnen). API-Schlüssel (Gemini, Pexels) bleiben nur im Browser des Nutzers.

**Daten:** Worthäufigkeit aus [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (OpenSubtitles, CC BY-SA 4.0) · Nomen/Artikel/Plural aus [german-nouns](https://github.com/gambolputty/german-nouns) (Wiktionary, CC BY-SA 4.0) · Fotos: [Pexels](https://www.pexels.com).
