# İÇ-19 — grammar.json İngilizce köprü temizliği (yazar kaydı)

Kural D-060. Yalnız aşağıdaki 23 girdinin `tr` alanı değişti; Almanca örnekler, sıra ve vurgular aynı.

- gr:a1-01:t2 — “to be” fiili → “olmak” fiili; 'Ich bin Tim.' = “I am Tim.” → = “Ben Tim'im.”
- gr:a1-02:t5 — İngilizcedeki “I am 30 (years old)” gibi → silindi; örnek sonuna = “Otuz yaşındayım.”
- gr:a1-09:t1 — (must / have to), (may / be allowed to), (want) → silindi (Türkçe karşılıklar zaten var)
- gr:a2-10:t1 — İngilizcedeki 'through' / 'around' gibi → silindi (Türkçe tanım zaten var)
- gr:a2-11:t3 — İngilizcedeki 'although' ile aynı. → silindi (“-e rağmen, …dığı hâlde” zaten var)
- gr:a2-12:t1 — İngilizcedeki *Could you tell me where the bank is?* gibi → silindi
- gr:a2-12:t2 — İngilizcedeki *whether / if* → silindi; “İngilizcedeki *if* yüzünden burada 'wenn' deme” → “burada 'wenn' deme”
- gr:a2-12:t3 — İngilizcedeki *I forgot to pay the bill.* gibi, ama 'zu' başta değil → (Faturayı ödemeyi unuttum.) 'zu' mastarın hemen önündedir.
- gr:a2-13:t5 — Yıldan önce İngilizcedeki gibi 'in' KULLANILMAZ → Yıldan önce 'in' KULLANILMAZ
- gr:b1-01:t1 — İngilizcedeki “had done” ile birebir aynıdır → silindi (“-mıştı/-mişti” zaten var)
- gr:b1-02:t1 — tıpkı İngilizcedeki “the series which is set in Regensburg” gibi → silindi
- gr:b1-02:t2 — İngilizcede “the film I saw” diyerek zamiri atabilirsin → silindi; “Almancada ilgi zamiri ASLA düşmez.” kaldı
- gr:b1-02:t4 — İngilizcedeki “the series everyone is talking about” gibi edatı sona bırakamazsın → Edat cümlenin sonuna kalmaz, zamirin önüne gelir
- gr:b1-05:t1 — İngilizcedeki “is done” yapısına → silindi (“-ılır/-ilir, -ınır” zaten var)
- gr:b1-06:t3 — İngilizcedeki “I have my car repaired” gibi → silindi (ettirgen “-tır/-dir” zaten var)
- gr:b1-07:t1 — İngilizcedeki “although” → silindi (“-masına rağmen” zaten var)
- gr:b1-07:t2 — İngilizcedeki “in case / if” → silindi (“eğer, … olursa” zaten var)
- gr:b1-08:t4 — ('both … and'), ('neither … nor') → silindi (“hem … hem de”, “ne … ne de” zaten var)
- gr:b1-09:t1 — ve İngilizcedeki “He’ll be at the doctor’s” kullanımına → silindi (tahmin “-dır” karşılaştırması kaldı)
- gr:b1-09:t3 — İngilizcedeki 'If I had known, I would have …' yapısının → silindi (“-seydi … -ırdı” zaten var)
- gr:b1-11:t1 — İngilizcedeki 'the more …, the better' yapısıdır → Türkçedeki “ne kadar … o kadar” yapısıdır
- gr:b1-12:t1 — İngilizcedeki 'while' / 'whereas' → silindi (“-ken”, “oysa, … ise” zaten var)
- gr:b1-12:t2 — İngilizcedeki 'as long as' → silindi (“-dığı sürece” zaten var)
